# FOUNDATION_CANONIZATION_SEQUENCE

Зафиксированный порядок канонизации Foundation-документов. Не меняется без отдельного owner ruling.

```text
1. Product Vision
2. Product Thesis
3. Product Principles
4. MVP Scope
5. User Journey
```

## Обоснование

```text
Vision отвечает — куда идёт продукт.
Thesis отвечает — почему этот продукт должен существовать и победить.
Principles отвечают — какие нормы неизменны.
MVP Scope отвечает — что входит в первый релиз.
User Journey отвечает — как человек проходит ключевые сценарии.
```

Каждый следующий документ опирается на утверждённые предыдущие: Thesis конкретизирует Vision; Principles нормируют то, что Vision и Thesis объявили; MVP Scope выбирает релизный состав в пределах Principles; User Journey раскрывает путь пользователя внутри утверждённого Scope.

## Правила выполнения

- Работа ведётся по одному документу за раз, в отдельном документном окне; следующий документ не начинается до owner approval предыдущего или отдельного разрешения владельца.
- Над всеми пятью документами стоят Ayla Product Essence v1.1 и Living Digital Twin Manifesto v1.0 (для LDT-тем); sibling-иерархия сохраняется.
- Текущий документ: **Product Vision**.
